# Personal Finance Tracker

<!-- impeccable:product-schema 1 -->

## Platform

web

## Product purpose

Track personal transactions in Indonesian rupiah, review monthly cash flow, and set category budgets. The existing application supports a local single owner and optional authentication.

## Capabilities and constraints

- Dashboard, transactions, monthly budgets, CSV export, and existing analytics API.
- Indonesian interface, Jakarta calendar dates, exact integer currency formatting.
- Preserve existing data, authentication, validations, and financial calculations.
- Existing React 19, React Router, TanStack Query, and Tailwind 4 stack.
- Light, dark, and system themes; responsive layouts and keyboard access.
- User requested improved frontend design and animations for charts, opening, closing, adding records, and page navigation.

## Confirmed direction

The user approved a tidy financial dashboard with teal accents, prominent amounts, and short, gentle animations on 18 October 2026. No additional product claims or audience assumptions are introduced.
